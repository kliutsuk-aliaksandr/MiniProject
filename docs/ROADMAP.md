# Roadmap — MiniProject

## Этап 1 — первый игровой прототип (0.1.0)

- [x] Android-проект на Kotlin.
- [x] Canvas и портретное игровое поле.
- [x] Движущаяся цепочка шаров.
- [x] Лягушка-пушка и управление касанием.
- [x] Вставка шара и матч трёх и более.
- [x] Счёт, рекорд, победа, проигрыш и перезапуск.
- [x] Unit-тесты базовой логики.
- [x] GitHub Actions для сборки и тестов.
- [ ] Проверить сборку и поведение на физическом Android-устройстве.

## Этап 2 — качество игрового процесса

- [ ] Проверить корректность вставки в разных местах цепочки.
- [ ] Улучшить анимацию столкновений и исчезновения шаров.
- [ ] Добавить звуковые эффекты и настройки звука.
- [ ] Добавить уровни и рост сложности.
- [ ] Добавить паузу и сохранение состояния раунда.

## Этап 3 — подготовка к публикации

- [ ] Иконка, скриншоты, описание и политика конфиденциальности.
- [ ] Проверка производительности и совместимости устройств.
- [ ] Подписание release-сборки и подготовка AAB.
- [ ] Закрытое тестирование и публикация в Google Play.

## Этап 4 — после завершения офлайн-версии

- [ ] Таблица рекордов и другие онлайн-функции.
- [ ] Реклама с настройками частоты и отключением.
- [ ] Покупки внутри приложения.
- [ ] Аналитика и события, необходимые для развития игры.
