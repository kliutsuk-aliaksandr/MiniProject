# Roadmap — MiniProject

## Этап 1 — первый игровой прототип (0.1.0)

- [x] Android-проект на Kotlin.
- [x] Canvas и портретное игровое поле.
- [x] Движущаяся цепочка шаров.
- [x] Лягушка-пушка и управление касанием.
- [x] Вставка шара и матч трёх и более.
- [x] Счёт, рекорд, победа, проигрыш и перезапуск.
- [x] Unit-тесты базовой логики.
- [x] GitHub Actions для сборки и тестов.
- [ ] Проверить сборку и поведение на физическом Android-устройстве.

## Этап 2 — качество игрового процесса (0.2.0)

- [x] Вставка шара с выбором передней/задней стороны по направлению столкновения.
- [x] Проверка попадания по отрезку движения снаряда, чтобы уменьшить пропуск шаров между кадрами.
- [x] Каскадное удаление групп, которые соединились после исчезновения предыдущей комбинации.
- [x] Частицы при удалении шаров.
- [x] Звуковые эффекты выстрела, совпадения, победы и поражения.
- [x] Кнопка включения/выключения звука.
- [x] Уровни с увеличением длины цепочки и скорости; каждые три уровня добавляется цвет.
- [x] Пауза, продолжение и перезапуск.
- [x] Сохранение текущего уровня, счёта, цветов и цепочки при уходе из приложения.
- [x] Unit-тесты вставки с обеих сторон, каскада, паузы, сохранения и прогрессии уровней.
- [ ] Проверить ощущения от управления, громкость и баланс сложности на реальном устройстве.

## Этап 3 — меню и управление (0.3.0)

- [x] Главное меню с продолжением сохранённой партии и новой игрой.
- [x] Экран настроек с выбором русского/английского языка и переключателем звука.
- [x] Отображение заряженного шара в пасти лягушки.
- [x] Поворот лягушки вслед за движением пальца; выстрел при отпускании.
- [x] Пауза с продолжением, перезапуском и возвратом в главное меню.
- [x] Возврат в меню системной кнопкой Back.

## Этап 4 — подготовка к публикации (0.4.0)

- [x] Иконка приложения: legacy vector и adaptive icon для Android 8+.
- [x] Название приложения Marble Frog и метаданные карточки Google Play на русском и английском.
- [x] Политика конфиденциальности в HTML/Markdown и внутри приложения.
- [x] Резервное копирование SharedPreferences в облако и device transfer отключены.
- [x] targetSdk 36 (Android 16), minSdk 23; проверка отсутствия ненужных разрешений и сетевых SDK.
- [x] R8 minification для release.
- [x] CI собирает debug APK, выполняет unit-тесты и формирует unsigned AAB.
- [ ] Добавить публичный email поддержки и опубликовать privacy-policy.html на публичном HTTPS URL.
- [ ] Подготовить реальные скриншоты с устройств и feature graphic для Play Store.
- [ ] Проверить производительность и совместимость на физических устройствах разных классов.
- [ ] Создать и сохранить резервную копию upload keystore; подписать AAB.
- [ ] Заполнить Data safety, content rating, target audience и остальные Play Console формы.
- [ ] Провести закрытое тестирование и подать заявку на production access, если это требуется аккаунту.
- [ ] Отправить подписанный AAB на проверку и опубликовать приложение.

- [x] Отдельный учебный экран и тренировочный режим из главного меню.
- [x] Карта из 30 уровней, разблокировка и локальные звёзды.
- [x] Бустеры: замедление, бомба, смена цвета и реверс цепочки.
- [x] Четыре типа дорожек и препятствия грязь/лёд/камни с разным влиянием на скорость.
- [x] Unit-тесты уровней, бустеров, препятствий, звёзд и тренировки.
