# Roadmap — MiniProject

## Этап 1 — первый игровой прототип (0.1.0)

- [x] Android-проект на Kotlin.
- [x] Canvas и портретное игровое поле.
- [x] Движущаяся цепочка шаров.
- [x] Лягушка-пушка и управление касанием.
- [x] Вставка шара и матч трёх и более.
- [x] Счёт, рекорд, победа, проигрыш и перезапуск.
- [x] Unit-тесты базовой логики.
- [x] GitHub Actions для сборки и тестов.
- [ ] Проверить сборку и поведение на физическом Android-устройстве.

## Этап 2 — качество игрового процесса (0.2.0)

- [x] Вставка шара с выбором передней/задней стороны по направлению столкновения.
- [x] Проверка попадания по отрезку движения снаряда, чтобы уменьшить пропуск шаров между кадрами.
- [x] Каскадное удаление групп, которые соединились после исчезновения предыдущей комбинации.
- [x] Частицы при удалении шаров.
- [x] Звуковые эффекты выстрела, совпадения, победы и поражения.
- [x] Кнопка включения/выключения звука.
- [x] Уровни с увеличением длины цепочки и скорости; каждые три уровня добавляется цвет.
- [x] Пауза, продолжение и перезапуск.
- [x] Сохранение текущего уровня, счёта, цветов и цепочки при уходе из приложения.
- [x] Unit-тесты вставки с обеих сторон, каскада, паузы, сохранения и прогрессии уровней.
- [ ] Проверить ощущения от управления, громкость и баланс сложности на реальном устройстве.
