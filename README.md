# MiniProject — Marble Frog

Небольшая офлайн-игра для Android в жанре **marble shooter**, вдохновлённая механикой Zuma.

Игрок управляет лягушкой-пушкой: запускает цветные шары в движущуюся цепочку и собирает группы из трёх и более одинаковых шаров.

## Текущая версия

**0.4.0 — анимация схлопывания и подготовка к публикации**

Возможности:
- вертикальное игровое поле с движущейся по дорожке цепочкой;
- главное меню: продолжение сохранённой партии, новая игра и настройки;
- выбор русского и английского языка с сохранением настройки;
- лягушка поворачивается вслед за пальцем при ведении по игровому полю, выстрел происходит при отпускании;
- вставка шара с учётом стороны попадания;
- удаление групп из трёх и более одинаковых шаров и каскадные комбинации;
- анимированное удаление: шары со стороны лягушки плавно откатываются к неподвижной дальней части цепочки;
- каскадные совпадения проверяются после завершения анимации;
- затухающие шары и частицы при совпадении;
- звуковые сигналы выстрела, совпадения, победы и поражения;
- кнопка включения/выключения звука;
- уровни: с каждым уровнем растёт длина цепочки и скорость, а каждые три уровня добавляется цвет;
- отдельный экран паузы с продолжением, перезапуском и возвратом в главное меню;
- автоматическое сохранение текущего уровня и цепочки при выходе из приложения;
- локальное сохранение рекорда;
- встроенная политика конфиденциальности;
- векторная и adaptive icon приложения;
- офлайн-работа без разрешения INTERNET.

Графика рисуется средствами Android Canvas. Звуки синтезируются Android ToneGenerator; внешние медиафайлы не нужны.

## Технологии

- Kotlin 2.4.21
- Android Gradle Plugin 8.13.2
- Gradle 8.13
- Android SDK 36
- Android Canvas
- Android ToneGenerator
- SharedPreferences для локального сохранения
- JUnit 4 для unit-тестов

## Запуск

1. Установи Android Studio и Android SDK Platform 36.
2. Открой папку репозитория в Android Studio.
3. Дождись синхронизации Gradle.
4. Запусти конфигурацию app на эмуляторе или физическом Android-устройстве.

Из командной строки:

**Windows**
~~~bat
gradlew.bat testDebugUnitTest
gradlew.bat assembleDebug
~~~

**Linux / macOS**
~~~bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
~~~

Скрипты gradlew и gradlew.bat скачивают закреплённую версию Gradle 8.13 в пользовательский Gradle-каталог при первом запуске. Требуется JDK 17 или новее и доступ к интернету для первоначальной загрузки Gradle и Android-зависимостей.

Debug APK и unsigned release AAB после успешной CI-сборки:
**app/build/outputs/apk/debug/app-debug.apk**  
**app/build/outputs/bundle/release/app-release.aab** (unsigned; перед Google Play нужно подписать)

## Управление

- Веди пальцем по полю — лягушка поворачивается за пальцем; отпусти палец, чтобы выстрелить.
- Цвет заряженного шара всегда виден в пасти лягушки.
- Нажми на **NEXT** вверху справа, чтобы поменять текущий шар со следующим.
- Кнопка с динамиком включает/выключает звуки.
- Кнопка паузы открывает меню с продолжением, перезапуском и возвратом в главное меню.
- В главном меню доступны продолжение, новая игра и настройки; в настройках можно выбрать русский или английский язык.
- Собери три или более шаров одного цвета; передняя часть цепочки откатывается назад, а задняя остаётся на месте. Каскад проверяется после схлопывания.
- После очистки цепочки выбери следующий уровень.
- При выходе из приложения текущий уровень сохраняется и при следующем запуске открывается на паузе.
