# MiniProject — Marble Frog

Небольшая офлайн-игра для Android в жанре **marble shooter**, вдохновлённая механикой Zuma.

Игрок управляет лягушкой-пушкой: запускает цветные шары в движущуюся цепочку и собирает группы из трёх и более одинаковых шаров.

## Текущая версия

**0.1.0 — первый игровой прототип**

Уже реализовано:
- вертикальное игровое поле с движущейся по дорожке цепочкой;
- лягушка-пушка и стрельба касанием;
- пять цветов шаров;
- вставка шара в цепочку и удаление совпадающих групп от трёх шаров;
- начисление очков и локальное сохранение рекорда;
- смена текущего и следующего шара нажатием на панель NEXT;
- победа при очистке цепочки, проигрыш при достижении финиша и перезапуск;
- офлайн-работа без разрешений на интернет.

Графика рисуется средствами Android Canvas — внешние ассеты не требуются.

## Технологии

- Kotlin 2.4.21
- Android Gradle Plugin 8.13.2
- Gradle 8.13
- Android SDK 36
- Android Canvas
- JUnit 4 для unit-тестов

## Запуск

1. Установи Android Studio и Android SDK Platform 36.
2. Открой папку репозитория в Android Studio.
3. Дождись синхронизации Gradle.
4. Запусти конфигурацию app на эмуляторе или физическом Android-устройстве.

Из командной строки:

**Windows**
~~~bat
gradlew.bat testDebugUnitTest
gradlew.bat assembleDebug
~~~

**Linux / macOS**
~~~bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
~~~

Скрипты gradlew и gradlew.bat скачивают закреплённую версию Gradle 8.13 в пользовательский Gradle-каталог при первом запуске. Требуется JDK 17 или новее и доступ к интернету для первоначальной загрузки Gradle и Android-зависимостей.

Debug APK после успешной сборки:
**app/build/outputs/apk/debug/app-debug.apk**

## Управление

- Нажми на игровое поле — лягушка выстрелит в направлении касания.
- Нажми на панель NEXT в правом верхнем углу — поменяешь текущий шар со следующим.
- Собери три или более шаров одного цвета.
- Если цепочка достигнет финиша, игра закончится.
- После победы или поражения нажми на экран, чтобы начать заново.
