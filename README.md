# MiniProject

Небольшая офлайн-игра для Android в жанре marble shooter (вдохновлена механикой Zuma).

## Технологии

- Kotlin
- Android SDK
- Android Canvas для 2D-отрисовки
- Gradle Kotlin DSL

## Статус

Стартовая версия проекта: архитектура, базовый игровой прототип и документация находятся в разработке.

## Запуск

Откройте репозиторий в Android Studio, дождитесь синхронизации Gradle и запустите конфигурацию `app` на эмуляторе или Android-устройстве.

## План MVP

1. Вертикальное игровое поле и извилистая дорожка.
2. Движущаяся цепочка цветных шаров.
3. Пушка, направляемая касанием экрана.
4. Удаление групп из трёх и более одинаковых шаров.
5. Очки, экран проигрыша и перезапуск.

Реклама, покупки и сетевые функции намеренно отложены до завершения офлайн-версии.
